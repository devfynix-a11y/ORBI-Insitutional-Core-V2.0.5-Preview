# ORBI Registration Blueprints

This folder contains the canonical blueprints for ORBI registration, identity
families, source channels, and access upgrade protocols.

Start here:

- [ORBI Global Registration Protocol](./ORBI_GLOBAL_REGISTRATION_PROTOCOL.md)
- [ORBI Registration Families](./ORBI_REGISTRATION_FAMILIES.md)
- [ORBI External Registration Gateway Contract](./ORBI_EXTERNAL_REGISTRATION_GATEWAY_CONTRACT.md)
- [ORBI Business Access Approval Flow](./ORBI_BUSINESS_ACCESS_APPROVAL_FLOW.md)
- [ORBI Service Actor Registration Rules](./ORBI_SERVICE_ACTOR_REGISTRATION_RULES.md)
- [ORBI API Request Contracts](./ORBI_API_REQUEST_CONTRACTS.md)

These documents protect ORBI from registration drift across mobile, web,
business, gateway, merchant, agent, and organization surfaces.

Endpoint summaries are included in each blueprint. The highest-level endpoint
matrix is in the Global Registration Protocol, while headers and request
payload examples are in the API Request Contracts document.
