# Cloudflare R2 Image Storage

ORBI uses Cloudflare R2 only for public or sanitized images such as avatars,
merchant images, and application artwork. KYC documents, signatures, regulated
evidence, and authoritative backups remain on private ORBI-controlled storage.

## Cloudflare setup

1. Create a dedicated R2 bucket such as `orbi-images`.
2. Create an R2 API token limited to Object Read and Write for that bucket.
3. Attach the custom domain `media-stock.orbifinancial.com`.
4. Keep the default `r2.dev` public URL disabled.
5. Configure CORS only for approved ORBI application origins if browser uploads
   or browser-side reads require it.
6. Configure lifecycle rules for abandoned or superseded objects.

Do not use an account-wide Cloudflare API token.

## Core configuration

```env
ORBI_IMAGE_STORAGE_PROVIDER=r2
ORBI_IMAGE_MAX_BYTES=5242880
CLOUDFLARE_ACCOUNT_ID=<ACCOUNT_ID>
CLOUDFLARE_ACCESS_KEY_ID=<BUCKET_SCOPED_ACCESS_KEY>
CLOUDFLARE_SECRET_ACCESS_KEY=<BUCKET_SCOPED_SECRET>
CLOUDFLARE_BUCKET_NAME=orbi-images
CLOUDFLARE_PUBLIC_URL_PREFIX=https://media-stock.orbifinancial.com
```

The custom image domain is required because profile records store durable avatar
URLs. Expiring presigned URLs must not be stored as profile data.

Keep these values only in the untracked `.env` or the VM secret store. If a
secret is pasted into chat, logs, tickets, or source control, revoke it and
create a replacement before deployment.

## Upload policy

- Accepted formats: JPEG, PNG, and WEBP.
- File MIME type must match its binary signature.
- Default maximum size: 5 MiB.
- Object names are generated by the server and cannot be supplied by clients.
- New avatars are uploaded before the previous object is deleted.
- Uploaded objects include only non-sensitive ownership and purpose metadata.

HEIC is intentionally rejected until a trusted image-normalization pipeline
converts it to a browser-safe format and strips metadata.

## Privacy boundary

Anything delivered from the public image domain must be treated as publicly
retrievable. Do not upload:

- national IDs or passports;
- KYC selfies;
- signatures;
- receipts containing sensitive account information;
- internal audit or dispute evidence.

Those objects belong in the private MinIO module with authenticated, short-lived
download access.
